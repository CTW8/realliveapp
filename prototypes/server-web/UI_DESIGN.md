⏺ 根据对项目的全面分析，我已经了解了 Android App 的完整设计。以下是 Web 端设计思路：

  ---
  Web 端设计思路

  一、设计定位差异

  ┌──────────┬──────────────────────┬───────────────────────────────┐
  │   维度   │     Android App      │            Web 端             │
  ├──────────┼──────────────────────┼───────────────────────────────┤
  │ 使用场景 │ 移动巡检、即时查看   │ 长时间坐席监控、集中管理      │
  ├──────────┼──────────────────────┼───────────────────────────────┤
  │ 屏幕尺寸 │ 375×812 单列         │ 1280~1920+ 多列布局           │
  ├──────────┼──────────────────────┼───────────────────────────────┤
  │ 交互方式 │ 触摸、滑动、底部导航 │ 鼠标+键盘、侧边导航、右键菜单 │
  ├──────────┼──────────────────────┼───────────────────────────────┤
  │ 信息密度 │ 中等（单任务聚焦）   │ 高（多任务并行、一屏多信息）  │
  ├──────────┼──────────────────────┼───────────────────────────────┤
  │ 核心价值 │ 快速看一眼           │ 长时间盯、批量管、深度查      │
  └──────────┴──────────────────────┴───────────────────────────────┘

  二、页面架构（建议 8 个核心页面）

  ┌─────────────────────────────────────────────────┐
  │  顶部栏: Logo | 搜索 | 通知铃铛 | 用户头像      │
  ├──────────┬──────────────────────────────────────┤
  │          │                                      │
  │  侧边导航  │        主内容区                      │
  │          │                                      │
  │  Dashboard│                                      │
  │  实时监控  │                                      │
  │  回放     │                                      │
  │  告警中心  │                                      │
  │  设备管理  │                                      │
  │  存储管理  │                                      │
  │  系统设置  │                                      │
  │          │                                      │
  └──────────┴──────────────────────────────────────┘

  各页面对应关系与 Web 扩展：

  1. Dashboard（仪表盘） — 对应 App 的 Dashboard + 通知
  - 保留：在线/离线/告警统计卡片、摄像头预览缩略图
  - Web 扩展：
    - 增加趋势图表（近7天告警趋势、存储用量曲线）
    - 增加设备地图概览（GIS 地图标注摄像头位置）
    - 实时告警滚动条（类似 Ticker）
    - 系统健康度看板（CPU/带宽/存储利用率）

  2. 实时监控（Live Monitor） — 对应 App 的 Multi View + Live View
  - 保留：视频流播放、PTZ 控制、截图/录像按钮
  - Web 扩展：
    - 灵活宫格布局：1×1 / 2×2 / 3×3 / 4×4 / 自定义布局
    - 宫格内可拖拽排列摄像头
    - 双击放大单路全屏，ESC 退回宫格
    - 分屏对比（左右/上下两路同时查看）
    - 轮巡模式（自动按组切换摄像头画面）
    - 画面上叠加 OSD（时间戳、摄像头名称、录制状态）

  3. 历史回放（Playback） — 对应 App 的 History Playback + Calendar + Event Detail
  - 保留：日历选择、时间轴、倍速播放
  - Web 扩展：
    - 多路同步回放（最多 4 路同时间段对比）
    - 时间轴增加拖拽框选截取片段
    - 事件标记在时间轴上可点击跳转
    - 视频片段下载/导出面板（选择时间段、格式、分辨率）
    - 智能事件筛选侧栏（按类型、摄像头、时间范围过滤）

  4. 告警中心（Alert Center） — 对应 App 的 Notifications
  - 保留：告警列表、类型图标、时间戳、缩略图
  - Web 扩展：
    - 告警表格视图（可排序、可筛选、可分页）
    - 批量操作（批量已读、批量删除、批量归档）
    - 告警详情侧边抽屉（点击列表项不跳转页面，右侧滑出详情）
    - 告警规则配置（触发条件、通知方式、静默时段）
    - 告警统计图表（按类型/设备/时段的分布图）

  5. 设备管理（Device Manager） — 对应 App 的 Camera List + Camera Settings + Add Camera
  - 保留：设备列表、状态指示、设备配置表单
  - Web 扩展：
    - 表格+卡片双视图切换
    - 批量操作（批量重启、批量升级固件、批量修改配置）
    - 设备分组/标签管理
    - 设备详情页（合并 App 中的 Camera Settings，展示更多参数）
    - 设备拓扑图（网络连接状态可视化）

  6. 存储管理（Storage） — 对应 App 的 Storage Management
  - 保留：环形图、分类用量
  - Web 扩展：
    - 存储趋势图（预测何时用满）
    - 按设备/日期的存储明细表
    - 存储策略配置（保留天数、覆盖策略、云同步设置）
    - 一键清理缓存/过期录像

  7. 系统设置（Settings） — 对应 App 的 Settings + Profile + Security
  - 保留：账户信息、安全设置、语言/主题
  - Web 扩展：
    - 用户/角色管理（多用户场景，App 端没有）
    - 操作审计日志
    - 系统参数配置（NVR 参数、网络配置）
    - 邮件/推送通知渠道设置

  8. 登录页（Login） — 对应 App 的 Splash + Login + Register
  - 保留：邮箱密码登录、注册
  - Web 扩展：居中卡片式布局，左侧品牌展示 + 右侧表单

  三、设计风格延续与适配

  继承自 App 的设计语言：
  - 深色主题 --bg: #1C1B1F，保持专业监控氛围
  - 紫/粉色调 --pri: #C8BFFF 作为品牌色
  - 语义色彩：绿色在线、橙色录制/警告、红色离线/告警
  - Material Symbols Outlined 图标体系
  - 圆角体系（4/8/12/16/28px）

  Web 端适配调整：
  - 字号整体放大（正文 14px、标题 18-24px），适应桌面阅读距离
  - 间距适当加大（行间距、卡片间距），利用大屏空间
  - 增加 hover 态、focus 态、键盘导航支持
  - 侧边栏可折叠（图标模式 / 展开模式）
  - 表格组件大量使用（App 中偏列表，Web 中偏表格）

  四、响应式策略

  ≥1440px  完整布局（侧栏展开 + 多列内容）
  1024-1439px  侧栏折叠为图标模式，内容区自适应
  768-1023px   顶部导航替代侧栏，单列布局
  <768px       基本不考虑（引导用户使用 App）

  五、Web 独有功能（App 没有的）

  1. 多路同屏监控（最多 16 宫格）
  2. 轮巡/巡航计划配置
  3. 用户权限管理（管理员/操作员/访客角色）
  4. 操作日志审计
  5. 数据导出（CSV/PDF 报表）
  6. 键盘快捷键支持（空格暂停、方向键 PTZ、数字键切宫格）
  7. 电子地图（GIS 设备标注）
  8. 全屏沉浸模式（F11 隐藏所有 UI，纯视频墙）
